# 🍫 ChocoBar Order & Queue System

ระบบจัดการเมนู บิลช็อกโกแลต และคิวห้องครัว พัฒนาด้วยภาษา Java โดยประยุกต์ใช้โครงสร้างข้อมูล (Data Structures) 3 รูปแบบ เพื่อจำลองการทำงานในร้านคาเฟ่จริง

## โครงสร้างข้อมูลที่ใช้ในระบบ (Data Structures)
1. **Tree (Menu Category Tree):** ใช้จัดเก็บและแสดงผลหมวดหมู่เมนูอาหารและเครื่องดื่มในรูปแบบลำดับชั้น (Hierarchical Structure)
2. **Stack (Bill Management - LIFO):** ใช้จัดการรายการอาหารในบิลปัจจุบัน รองรับการเพิ่มรายการ (`push`) และการยกเลิกรายการล่าสุด (`pop`) ตามหลัก Last-In, First-Out
3. **Queue (Kitchen Queue - FIFO):** ใช้จัดลำดับออเดอร์ที่ลูกค้ายืนยันส่งต่อให้ห้องครัว โดยเรียงตามลำดับก่อน-หลัง ตามหลัก First-In, First-Out (`offer` และ `poll`)

---

##  ฟังก์ชันการทำงานหลัก (Features)
-  **แสดงเมนูอาหาร:** ดูรายการช็อกโกแลตและของหวานตามหมวดหมู่
-  **สั่งอาหาร (Push to Stack):** เพิ่มรายการเมนูลงในบิลชั่วคราว
-  **ยกเลิกรายการล่าสุด (Pop from Stack):** ใช้ปุ่ม Undo เพื่อยกเลิกรายการที่เพิ่งสั่งไป
-  **ยืนยันบิลและส่งเข้าครัว (Enqueue Queue):** เปลี่ยนบิลปัจจุบันให้เป็นออเดอร์ส่งเข้าครัว และล้างบิลเตรียมรับออเดอร์ถัดไป
-  **ห้องครัวทำอาหารเสร็จ (Dequeue Queue):** ดึงออเดอร์แรกสุดในคิวออกเมื่อทำเสร็จ
-  **แสดงข้อมูลคิวและบิล:** ตรวจสอบสถานะคิวในครัวทั้งหมดแบบเรียลไทม์
